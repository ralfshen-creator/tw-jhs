# 國中自然科學學習站（Natural Science）

給國中生用的自然科學學習網站（目前收錄理化：物理、化學）：課程重點、公式卡、測驗、錯題本、學習紀錄、考古題匯入。
章節依 108 課綱、**翰林版**國中自然科學編排。自然科學包含生物、理化、地球科學，目前收錄八上到九下的理化章節；生物（七年級）與地球科學尚未收錄。
**八上已完整製作**（預備章 + 第 1～6 章，節次名稱對齊翰林版），八下以後目前是精簡版。

## 怎麼開

**直接雙擊 `index.html`** 用 Chrome 或 Edge 開啟即可，不需要安裝任何東西、不需要網路。

> 學習紀錄存在瀏覽器裡，而且「用什麼方式開」會分開存。
> 請固定用同一個瀏覽器、同一種方式開（例如一律雙擊 `index.html`），否則會看起來像紀錄不見。

## 功能

| 頁面 | 內容 |
|---|---|
| 課程 | 每章重點整理、例題、易錯觀念；可勾選「讀完了」 |
| 公式卡 | 全部章節公式彙整，可列印 |
| 測驗 | 自選章節、題數、題型、來源；練習模式（每題立刻對答案）或考試模式（可限時、交卷才公布） |
| 錯題本 | 答錯自動收錄，連續答對 2 次自動移出；可按章節重練 |
| 學習紀錄 | 各章正確率、測驗歷史 |
| 題庫 / 匯入 | 匯入考古題、手動新增題目、瀏覽／刪除、備份與還原 |

出題方式預設「優先出沒做過與答錯的」，會自動把弱點題目排在前面。

## 匯入考古題

到網站的「題庫 / 匯入」頁，三種方式擇一：

1. **Excel → CSV**：照 `templates/考古題範本.csv` 的欄位填，另存成 CSV 後上傳
2. **Excel 直接複製貼上**：在 Excel 選取整個表格（含標題列）複製，貼到文字框
3. **JSON**：格式見網站上「下載 JSON 範本」

欄位（只有「題目」「答案」必填）：

```
章節,題型,題目,選項A,選項B,選項C,選項D,答案,解析,來源,年份,難度,圖片
```

- **章節**：代碼如 `8A-1`（八上第1章），或章節名稱如 `基本測量`。空白時歸到匯入時選的預設章節
  （會考、模擬考這類跨章節的題目可以歸到 `misc 未分類 / 綜合`）
- **題型**：單選／多選／是非／填充，空白會自動判斷
- **答案**：單選 `B`、多選 `ACD`、是非 `O`/`X`、填充可用 `|` 分隔多個可接受答案（`水|H2O`）
- **圖片**：把圖檔放進 `images/` 資料夾，這裡填檔名
- 匯入前會先「檢查內容」，列出有問題的列；題目與答案完全相同的會自動略過

## 段考衝刺

首頁最上方的「段考衝刺」卡片會列出這次段考的範圍、讀書順序和模擬考按鈕。
換下一次段考範圍時，改 `data/curriculum.js` 最上面的 `EXAM_FOCUS`：

```js
window.EXAM_FOCUS = {
  title: "八上第二次段考",
  chapters: ["8A-3", "8A-4"],   // 章節代碼（8A-0 是預備章「實驗室常用器材」）
  questions: 25,               // 模擬考題數
  minutes: 45                  // 模擬考時間
};
```

## 修改課程內容

| 檔案 | 用途 |
|---|---|
| `data/curriculum.js` | 章節與重點內容。章節名稱或順序和課本不同時改這裡 |
| `data/questions.js`、`questions2.js`、`questions3.js` | 內建練習題（questions2／3 是 2026-10-11 擴充的 164 題自編原創題；考古題請用網站匯入，不用改這裡） |
| `data/figures.js`～`data/figures6.js` | 課程與題目用的圖解（SVG）；figures4.js 含資料表 `FIG.table()` 與擴充題用的統計圖；figures5／6.js 是八下、九年級課文的圖解（只用在課文，不用在考題） |
| `data/concepts.js` | 知識點對照：每題連到章節、小節與常見錯誤 |
| `js/sim-common.js` | 模擬器共用的「預測 → 觀察 → 解釋」任務 |
| `js/sim-wave.js`、`js/sim-ohm.js`、`js/sim-circuit.js`、`js/sim-lens.js` | 波動（橫波、縱波）、歐姆定律、串並聯、凸透鏡成像模擬器（上方選單「模擬實驗」） |
| `js/app.js` | 頁面與測驗邏輯 |
| `js/importer.js` | CSV / JSON 匯入解析 |
| `js/storage.js` | 瀏覽器儲存與備份 |
| `css/style.css` | 外觀（支援深色模式） |

## 注意

- 課程重點與內建題目是依課綱自編的，**不是翰林課本原文**。章節名稱若與孩子手上的課本有出入，以課本為準，改 `data/curriculum.js` 即可
- 換電腦或清除瀏覽資料前，請到「題庫 / 匯入」→「匯出備份檔」
