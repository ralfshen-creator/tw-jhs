# 數學｜國小數學學習站（五年級）

| 項目 | 內容 |
|---|---|
| 年級 | 五年級（之後加六年級） |
| 版本 | 康軒版（115 學年度） |
| 學習紀錄前綴 | `esma.` |
| 狀態 | 已完成五上、五下；**尚未經老師複核** |

## 內容

- 五上、五下各 10 個單元，共 62 節課程重點：條列重點、例題（含步驟）、易錯提醒、生活比喻
- 24 張課文圖解、9 張看圖題用圖（SVG，支援深色模式；看圖題的圖不標答案）
- 每單元公式卡
- 內建題庫 180 題（每單元 9 題），全部自編：觀念、計算、看圖、生活情境；每題有解析與常見錯誤
- 填充題可以寫帶分數（例如 `2又7/10`）或假分數

## 單元名稱的依據

- 單元名稱：學校公告的 115 學年度康軒版五年級數學教學計畫（第一單元「多位小數與加減」），以及均一教育平台「適康軒版（115 學年）」課程。
- 小節名稱是本站整理，可能和課本的活動名稱不完全一樣。

## 待確認（請老師或家長對照課本）

- 五上第 5 單元：本站放了「扇形與圓心角」一節（依課程表「多邊形 └扇形與圓心角」）；多邊形內角和只放三角形、四邊形，五邊形以上當作延伸。
- 五上第 3 單元：只放 2、5、10 的倍數判別，3 的倍數判別沒有放。
- 五下第 8 單元：「打八折」是生活例子，課本是否在五年級教折扣請確認。
