## 點英文念出來（2026-10-26 加入）

- `js/speak.js`（只有英語站載入，不動共用的 app.js）：用瀏覽器內建的英語語音（Web Speech API）念出來，不需要錄音檔、不需要網路服務。
- 課文、句型卡、題目題幹、解析、圖裡的英文都可以點；測驗選項不加（點選項是作答）。課文頁上方有「慢速」開關（記在這台裝置）。
- 不念：少於 3 個字母的片段（ai、er 等拼讀組合）、緊接在「不是」後面的錯誤示範（例如「不是 fourty」）。
- 聲音品質依裝置而定：iPad／iPhone、Windows、Android、Chrome 都有內建英語語音；少數沒有英語語音的裝置會用預設聲音念。
