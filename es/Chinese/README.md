# 國語｜國小國語學習站（五、六年級）

| 項目 | 內容 |
|---|---|
| 年級 | 五、六年級 |
| 版本 | 南一版（115 學年度） |
| 學習紀錄前綴 | `esch.` |
| 狀態 | 已完成五上、五下、六上、六下；**尚未經老師複核** |

## 內容

- 五上：壹 品格小學堂、貳 自然筆記、參 用心看世界、肆 作家風華
- 五下：壹 感受生活、貳 智慧之鑰、參 愛的協奏曲、肆 文明時光機
- 六上：壹 美好時刻、貳 工作圖像、參 問題解決、肆 文學之窗（12 課）；六下：壹 童年你我他、貳 往夢想起飛、參 給年輕的你（9 課）
- 六年級（2026-10-23 加入）：2 張圖（律詩結構、敘事人稱）、79 題；檔案 `curriculum6.js`、`figures6.js`、`concepts6.js`、`questions6.js`；杜甫〈客至〉列出全文
- 每個單元分四部分：三課的學習重點，加上該單元的語文天地
- 重點包括：句型（假設、選擇、遞進、連貫、轉折、因果、並列、條件、目的）、修辭（譬喻、擬人、疊字、摹寫、排比、引用）、褒義詞和貶義詞、標點（夾注號、破折號）、絕句、小說三要素、議論文、說明文、訪問稿、閱讀方法
- 2 張圖（議論文架構、起承轉合）
- 內建題庫 80 題（每單元 10 題），全部自編

## 依據

- 單元、課名、每課學習目標：屏東縣多所國小公告的「115 學年度五年級國語教學進度總表」（標示版本：南一），彼此交叉比對。
- **不收錄課文和生字表**（課文有著作權）。各課只整理學習重點，例句、短文、題目都是本站自己寫的。
- 六年級：屏東縣兩所國小（134604、134614）公告的 115 學年度六年級國語教學計畫，版本欄都標示南一，兩份一致。注意：同縣也有不少學校六年級用翰林（第一課〈遇見自己〉）或康軒（第一課〈跑道〉），本站已排除。
- 唐詩〈鳥鳴澗〉（王維）、〈早發白帝城〉（李白）是古典作品，列出全文和白話說明。

## 待確認（請老師或家長對照課本）

- 「特別的海」介紹哪些海景、「沉默的動物園」寫的是哪些古文明遺跡，本站只做一般性說明，以課本為準。
- 生字、新詞、注音沒有收錄，請用課本和習作練習。
- 六年級〈戲術〉〈機智的孩子〉〈紀念照〉等課的出處和情節，本站只做一般性說明，以課本為準。
