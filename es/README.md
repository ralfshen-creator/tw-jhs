# es｜LVUP 學習網的國小高年級部分

網址 `…/es/`。上一層是 LVUP 首頁。目前做五年級，之後再加六年級。

## 科目與課本版本（2026-10 家長提供，依孩子學校目前使用的課本）

| 科目 | 版本 | 狀態 | 位置 |
|---|---|---|---|
| 數學 | 康軒 | ✅ 五上、五下 20 個單元、180 題 | `Math\` |
| 國語 | 南一 | 尚未開始 | — |
| 英語 | 康軒 | 尚未開始 | — |
| 社會 | 康軒 | ✅ 五上、五下 8 個單元、21 課、80 題 | `Social\` |
| 自然 | 康軒 | ✅ 五上、五下 8 個單元、80 題 | `Science\` |

**新增一個科目時**：在該科資料夾做好網站後，到 `portal\subjects.js` 把那一科的 `status` 改成 `"ready"`、填上 `href`；並把該站的學習紀錄前綴加進根目錄 `js\home-auth.js` 的 `SITE_PREFIXES`。

學習站沿用國中的學習引擎（`js\app.js` 等），只換 `data\` 裡的課程、題庫和 `data\site.js` 的設定（`publisher` 課本版本、`capRange: null` 表示沒有會考）。
