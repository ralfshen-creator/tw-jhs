# 數學｜國中數學學習站

| 項目 | 內容 |
|---|---|
| 所屬領域 | 數學 |
| 年級 | 七～九年級 |
| 版本 | 翰林版（章名、節名依升學王版本對照表的翰林欄；三家版本涵蓋的單元相同，數學沒有其他版本才有的補充教材） |
| 會考 | ✅ |
| 狀態 | 已完成（2026-10-12 已依複核意見修正） |

## 內容

- 24 章、61 節課程重點：條列重點、例題（含步驟）、易錯提醒、生活比喻
- 26 張課文圖解（SVG，支援深色模式）
- 每章公式卡
- 內建題庫 185 題，全部自編，沒有抄錄課本、考古題或會考題目
  - 題型：單選、多選、是非、填充
  - 每題都有解析與常見錯誤，答錯時會連回對應的課文那一節
  - 涵蓋觀念、計算、圖表判讀、生活情境

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 入口 |
| `data/site.js` | 本站設定：科目名稱、年級、主題標籤、會考範圍、紀錄的儲存前綴 `ma.` |
| `data/curriculum.js` / `curriculum2.js` / `curriculum3.js` | 七／八／九年級課程 |
| `data/figures.js` | 課文圖解 |
| `data/concepts.js` | 觀念與常見錯誤，給答錯時的提示用 |
| `data/questions.js` / `questions2.js` / `questions3.js` | 七／八／九年級題庫 |
| `css/`、`js/` | 沿用理化站的程式，改成讀 `site.js` 的設定 |

## 上線

可以單獨上線（把 `Math\` 資料夾拖到 Netlify），也可以整個 `TW_JHS\` 一起上線。
學習紀錄存在瀏覽器裡、依網址分開，換網址前請先在「題庫 / 匯入」備份。
