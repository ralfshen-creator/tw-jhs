# 開通登入功能：Firebase 設定步驟

網站的登入與雲端紀錄用 Google 的 Firebase（免費方案就夠用）。下面的步驟要用**家長的 Google 帳號**在 Firebase 主控台操作，大約 10 分鐘。做完把第 6 步複製到的設定傳給 Claude，或自己貼進兩個 `firebase-config.js`。

> 畫面上的按鈕名稱可能因 Firebase 改版略有不同，找意思相近的就可以。

## 1. 建立專案

1. 打開 <https://console.firebase.google.com/>，用家長的 Google 帳號登入。
2. 按「建立專案」（或「新增專案」），名稱例如 `tw-lvup`。
3. 「Google Analytics」可以關掉，用不到。按「建立專案」。

## 2. 開啟兩種登入方式

1. 左邊選單「建構」→「Authentication」→「開始使用」。
2. 「登入方式」（Sign-in method）分頁：
   - 點「電子郵件/密碼」→ 打開第一個開關（**不用**打開「電子郵件連結」）→ 儲存。
   - 點「新增供應商」→「Google」→ 打開開關 → 「專案的公開名稱」填 `國中學習網` → 「專案支援電子郵件」選家長的信箱 → 儲存。
     公開名稱會出現在 Google 登入的畫面上，同學才知道是在登入哪個網站。

## 3. 加入網站的網址（授權網域）

「Authentication」→「設定」（Settings）分頁 →「授權網域」→「新增網域」，把**所有會用到的網址**都加進去（只填網域，不要 `https://`）：

- `physchem-buddy.netlify.app`（現在的理化站）
- 之後整個國中學習網上線的網址，例如 `xxxx.netlify.app`
- `localhost` 預設已經有，不用加

沒加的網址按 Google 登入會出現「這個網址還沒加入授權網域」。

## 4. 建立資料庫（存學習紀錄）

1. 左邊選單「建構」→「Firestore Database」→「建立資料庫」。
2. 位置選 **`asia-east1`（台灣）**。位置建立後不能改。
3. 選「**以正式版模式啟動**」（production mode）→ 建立。
4. 上方「規則」分頁：把裡面的內容**全部刪掉**，貼上這個資料夾裡 `firestore.rules` 的全部內容 → 按「發布」。

這份規則讓每個人只能讀寫自己的紀錄，同學之間互相看不到。

## 5. 確認防護設定（通常預設就是對的）

「Authentication」→「設定」→「使用者動作」：確認「**電子郵件列舉保護**」是開啟的。這樣別人沒辦法用「忘記密碼」去試探某個信箱有沒有註冊。

## 6. 取得網站設定

1. 左上角齒輪 →「專案設定」→「一般」分頁，往下到「你的應用程式」。
2. 按網頁圖示 `</>` → 應用程式暱稱填 `TW_JHS` → **不用**勾 Firebase Hosting → 「註冊應用程式」。
3. 畫面會出現一段程式碼，裡面有 `const firebaseConfig = { apiKey: "...", authDomain: "...", ... }`。
   **複製大括號 `{ … }` 那一段**，傳給 Claude。

這些值不是密碼，放在網頁裡是 Firebase 的正常用法；資料安全靠第 4 步的規則。

## 之後

- 設定會填進 `Math\js\firebase-config.js` 和 `Science\PhysChem_Learning\js\firebase-config.js`，兩個要一樣，同一個帳號才能在各科共用。
- 改完要重新上傳到 Netlify。
- **建議整個 `TW_JHS\` 用同一個網址上線**：同一個網址下登入一次，數學和理化都是登入狀態；分開上線的話，每個網站要各登入一次（紀錄還是同一份）。
- 用量：免費方案每天可讀 5 萬次、寫 2 萬次，一般一個班的同學使用遠遠用不完。
- 要看有哪些人註冊：Firebase 主控台「Authentication」→「使用者」。
