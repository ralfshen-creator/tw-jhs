# jhs｜LVUP 學習網的國中部分（Taiwan Junior High School）

這個資料夾原本叫 `TW_JHS`，2026-10-21 起放在 `LVUP\jhs\`，網址是 `…/jhs/`。上一層是 LVUP 首頁（選擇學習階段）。

目標：做一個涵蓋整個國中（七～九年級）學習的網站。這份文件整理目前國中要學的科目，作為規劃依據。

| 領域 | 科目 | 每週節數（參考） | 會考是否考 |
|---|---|---|---|

| 數學 | 數學 | 4 | ✅ |

| 自然科學 | 生物（七年級）、理化（八、九年級）、地球科學（九年級） | 3 | ✅ 自然 |

- 節數是課綱的參考配置，**各校實際課表會微調**，例如自然科學有的學校九年級排理化 2 節、地球科學 1 節。

## 三、資料夾結構

```
jhs\
├─ index.html            總入口首頁（依八大領域列出科目）
├─ portal\               首頁樣式 portal.css、科目清單 subjects.js
├─ shared\               之後各科共用的程式（規劃中）
├─ firebase\             登入功能的設定說明與安全規則
├─ Chinese\  English\  Math\（數學網站）
├─ Social\       History\  Geography\  Civics\
├─ Science\      PhysChem_Learning\（自然科學網站：生物、理化、地科）  Biology\  Earth_Science\（只有說明）
├─ Technology\   Info_Tech\
└─ Health_PE\    Health\
```

每個科目資料夾都有 README.md，寫明年級、所屬領域、會考是否考、目前狀態。

**本站只做 11 科**（2026-10-12 家長決定）：國文、英語、數學、歷史、地理、公民、生物、理化、地球科學、健康教育、資訊科技。
本土語文、音樂、視覺藝術、表演藝術、家政、童軍、輔導、生活科技、體育先拿掉（以實作、術科為主，做成網站幫助有限），資料夾移到 `Ralf_Claude\TW_JHS_removed_20261012\`，要加回來時搬回原位，並在 `portal\subjects.js` 補上那一科。

**新增一個科目時**：在該科資料夾做好網站後，到 `portal\subjects.js` 把那一科的 `status` 改成 `"ready"`、填上 `href`，首頁就會出現可以點的卡片。

## 四、上線方式

- **整個 LVUP 一起上線**（建議）：GitHub 儲存庫 `ralfshen-creator/tw-lvup` 的根目錄就是 LVUP 首頁，國中在 `/jhs/`，數學在 `/jhs/Math/`，自然科學在 `/jhs/Science/PhysChem_Learning/`。各站上方的「🎒 全部科目」回到國中總覽，國中總覽的「⬆️ LVUP」回到首頁
- **原本的理化網站**（physchem-buddy）照舊：只拖 `Science\PhysChem_Learning` 資料夾。單獨上線時不會顯示「全部科目」連結
- 注意：學習紀錄存在各網址自己的瀏覽器空間。換到總入口網址後，可以先在舊網站「題庫 / 匯入」下載備份，再到新網址還原

## 帳號登入與雲端紀錄

- 每個科目站都有「👤 登入」：可用 Google，或電子郵件＋密碼（可寄信重設密碼）。任何人都能註冊，方便分享給同學。
- 登入後學習紀錄存到 Firebase 雲端，換電腦、手機登入同一個帳號就能接著用；每個人只能讀寫自己的紀錄。
- 沒登入照常使用，紀錄存在這台電腦。登出會清掉這台電腦上的紀錄（資料仍在雲端），同學共用電腦也不會混到別人的紀錄。
- 開通方式見 `firebase\設定說明.md`；安全規則在 `firebaseirestore.rules`。設定值填在各站的 `jsirebase-config.js`（各站要一樣）。
- 程式：各站的 `js\cloud.js`（內容相同，改的時候要一起改）。

## 五、建議的做法（待討論）

1. **先做會考科目**：數學、英語、國文、社會、自然（補生物、地科），再做其他領域
2. **資料夾**：每科一個資料夾放在 `jhs\` 底下，例如 `Math\`、`English\`、`Chinese\`、`Social\`、`Science\`
3. **網站**：可以做成一個總入口網站，首頁選科目，各科共用同一套測驗、錯題本、學習紀錄；理化網站的程式可以直接沿用
4. 每一科都照理化的做法：依學校使用的版本（理化是翰林）編排課程、原創題目、教師複核文件
